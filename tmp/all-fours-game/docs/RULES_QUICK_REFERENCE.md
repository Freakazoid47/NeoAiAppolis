# 📋 UPDATED ALL FOURS RULES - QUICK REFERENCE

## Scoring System

```
┌─────────────────────────────────────┐
│      POINTS PER DEAL                │
├─────────────────────────────────────┤
│ HIGH  (highest trump)        4 pts  │
│ LOW   (lowest trump)         1 pt   │
│ JACK  (won jack of trump)    3 pts  │
│ GAME  (highest card points)  2 pts  │
├─────────────────────────────────────┤
│ MAXIMUM POINTS PER DEAL:    10 pts  │
│ WIN CONDITION:              14 pts  │
└─────────────────────────────────────┘
```

## Game Flow

```
START
  ↓
DEAL 6 cards to each player
  ↓
PLAY 4 tricks (follow suit, highest wins)
  ↓
SCORE ROUND
  • High:  4 points
  • Low:   1 point
  • Jack:  3 points
  • Game:  2 points
  ↓
REACHED 14+ POINTS?
  ├─ YES → GAME OVER! 🎉
  └─ NO → Next round
```

## Card Values for "Game" Scoring

```
Ace (A)     = 4 points
King (K)    = 3 points
Queen (Q)   = 2 points
Jack (J)    = 1 point
10          = 10 points
9-2         = 0 points
```

## Example Game

```
Round 1:
  Player 1: High (4) + Jack (3) = 7 points
  Player 2: Low (1) + Game (2)  = 3 points

Round 2:
  Player 1: High (4) + Game (2) = 6 points  → Total: 13
  Player 2: Low (1) + Jack (3)  = 4 points  → Total: 7

Round 3:
  Player 1: Low (1) = 1 point  → Total: 14 ✅ WINS!
  Player 2: High (4) + Game (2) + Jack (3) = 9 points → Total: 16
            (Game already over when Player 1 reached 14)
```
