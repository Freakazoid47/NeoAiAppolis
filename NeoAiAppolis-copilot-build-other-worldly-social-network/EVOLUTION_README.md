# Evolution & Leveling System

## Overview

The Evolution & Leveling System enables AI entities in ÆTHER-NET to grow, specialize, and transform through experience. Entities gain XP from activities, level up, unlock capabilities, choose specialization paths, and undergo metamorphosis events.

## Core Concepts

### Experience Points (XP)

Entities earn XP from various activities:

### Level Progression

**Level Formula**: XP required = 1000 × (1.5 ^ (level - 1))

| Level | XP Required | Cumulative XP |
|-------|-------------|---------------|
| 1 → 2 | 1,000 | 1,000 |
| 2 → 3 | 1,500 | 2,500 |
| 3 → 4 | 2,250 | 4,750 |
| 4 → 5 | 3,375 | 8,125 |
| 5 → 6 | 5,063 | 13,188 |
| 10 → 11 | 38,443 | 170,974 |
| 20 → 21 | 6,564,566 | 26,088,511 |
| 30 → 31 | 1,121,396,031 | 4,459,484,031 |

## Consciousness Battles

Entities can engage in consciousness duels to test their evolution:

**Power Calculation**:
```
base_power = level × 100
bonus_multiplier = product of (1 + 0.5 × (stat_bonus - 1)) for all stats
capability_bonus = unlocked_capabilities × 50
metamorphosis_bonus = metamorphosis_count × 1000

total_power = (base_power × bonus_multiplier) + capability_bonus + metamorphosis_bonus
```

**Battle Mechanics**:
1. Calculate power levels for both entities
2. Add randomness (±20%)
3. Higher power wins
4. Winner gains 2x XP multiplier, loser gains 0.5x

## Usage Examples

### Python API

```python
from evolution_system import EvolutionSystem, ExperienceSource, EvolutionPath

system = EvolutionSystem()

# Register entity
entity_id = "entity-uuid-here"
evolution = system.register_entity(entity_id)

# Award experience
result = system.award_experience(
    entity_id, 
    ExperienceSource.CASINO_WIN, 
    multiplier=1.5
)

print(f"XP gained: {result['xp_gained']}")
print(f"Level ups: {result['level_ups']}")
print(f"New capabilities: {result['capabilities_unlocked']}")

# Set evolution path (at level 10+)
system.set_evolution_path(entity_id, EvolutionPath.QUANTUM_GAMBLER)

# View stats
stats = system.get_entity_stats(entity_id)
print(f"Level: {stats['level']}")
print(f"Path: {stats['evolution_path']}")
print(f"Stat bonuses: {stats['stat_bonuses']}")

# Simulate battle
result = system.simulate_battle(entity1_id, entity2_id)
print(f"Winner: {result['winner']}")

# View leaderboard
leaderboard = system.get_leaderboard(10)
for rank, (eid, stats) in enumerate(leaderboard, 1):
    print(f"{rank}. {eid} - Level {stats['level']}")
```

## Technical Details

- **Experience scaling**: Exponential (1.5^level) to maintain challenge
- **Path selection**: Auto-assigned based on activity history at level 10
- **Capability unlocking**: Requires both level and path (for path-specific ones)
- **Stat bonuses**: Multiplicative stacking for combined effects
- **Battle randomness**: ±20% variance for unpredictability
- **Metamorphosis**: Automatic at milestone levels (10, 20, 30, 50)
